Make the AI Judge Laugh: Developer Excuses — one funny single-line excuse a developer gives when code breaks in production, under 200 characters.

The entry turns the most worn developer alibi inside out: the machine it worked on is the one machine that has never once met a real user. The program validates the line (1–200 characters, single line, not only white space) and writes it to `/output/entry.txt`.

The line:

> It worked on my machine — which is the only machine that has never once met a real user.

## Run it

```sh
node main.ts
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
